# Amphora installer

The one-line installer and the version file Amphora installs read when
"Check for new versions" is on. Nothing else lives here — no source.

```bash
curl -fsSL https://raw.githubusercontent.com/Parth-Kadakia/amphora-install/main/install.sh | bash -s <INSTALL CODE>
```

`latest.json` is updated by Amphora's release workflow on every version tag.
